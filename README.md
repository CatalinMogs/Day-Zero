# Day Zero

A text-adventure game where you have to survive the apocalypse by choosing the right answers.

## Features

<ul>
  <li> You start with food and water already loaded.</li>
  <li> Choose your own way to finish the game.</li>
  <li>Explore different locations to find supplies.</li>
</ul>
